## Overview

FinSight is a production-deployed personal finance dashboard that helps users track transactions, manage budgets, visualize spending patterns, and get AI-powered insights about their financial behavior.

Built as a portfolio project to demonstrate modern fullstack development skills using the tech stack most demanded by Indonesian and remote tech companies in 2025–2026.

## Features

### 📊 Dashboard
- **Summary cards** — Total income, expense, net balance, and saving rate for the current month
- **Trend chart** — Line chart comparing income vs expense over the last 6 months (Recharts)
- **Category pie chart** — Spending distribution by category
- **Budget progress** — Visual progress bars with color-coded status (safe / warning / danger)
- **Recent transactions** — Last 8 transactions with quick glance info
- **AI Insight card** — 3 personalized insights generated by Gemini 2.5 Flash based on real transaction data

### 💳 Transactions
- Full CRUD — add, edit, delete transactions
- Filter by type (income/expense), category, date range
- Full-text search by description
- Recurring transaction support (daily/weekly/monthly/yearly)
- Pagination with configurable page size

### 💰 Budget Management
- Set monthly spending limits per category
- Real-time progress tracking with color indicators
- Configurable alert thresholds (50–100%)
- Budget summary strip with totals

### 🤖 AI Spending Insights (Google Gemini)
- Queries user's actual transaction data — not generic advice
- Generates 3 personalized insights: spending patterns, budget warnings, saving tips
- Cached per month to minimize API calls
- Insight types: info, warning, tip, achievement

### 🔐 Authentication
- Email/password with NextAuth.js
- Google OAuth (one-click sign in)
- JWT session strategy with 30-day persistence
- Protected routes via Next.js middleware

### ⚙️ Settings
- Update profile name
- Select currency (IDR, USD, SGD, MYR)
- Select timezone (WIB, WITA, WIT)

```
├── app/

│   │   ├── page.tsx       # Main dashboard
│   │   ├── transactions/  # Transaction list & management
│   │   ├── budgets/       # Budget management
│   │   ├── analytics/     # Detailed analytics
│   │   └── settings/      # User settings
│   ├── api/
│   │   ├── auth/          # NextAuth + Register
│   │   ├── transactions/  # CRUD + filters
│   │   ├── budgets/       # CRUD + spending aggregation
│   │   ├── categories/    # System + custom categories
│   │   ├── dashboard/     # Aggregated dashboard data
│   │   ├── ai/insight/    # Google Gemini API integration
│   │   └── user/settings/ # Profile update
│   └── globals.css        # Tailwind v4 config + CSS vars
├── components/
│   ├── dashboard/         # Dashboard widgets
│   ├── transactions/      # Transaction list + form modal
│   ├── budgets/           # Budget manager + cards
│   ├── settings/          # Settings form
│   └── shared/            # Sidebar, Header, Providers
├── lib/
│   ├── prisma.ts          # Prisma client singleton
│   ├── auth.ts            # NextAuth config
│   ├── utils.ts           # Helper functions
│   └── validations.ts     # Zod schemas
├── hooks/                 # Custom React hooks
├── types/                 # TypeScript interfaces
├── prisma/
│   ├── schema.prisma      # Database schema
│   └── seed.ts            # Demo data seeder
└── middleware.ts          # Auth route protection
```

### Key Design Decisions

- **TypeScript strict mode** — `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, zero `any`
- **Server vs Client Components** — API calls in route handlers, UI state in client components
- **Parallel queries** — `Promise.all()` for dashboard data (summary + trend + categories in one round trip)
- **Response caching** — AI insights cached per user per month in PostgreSQL to avoid redundant API calls
- **Row-level security** — Every query filters by `userId` from session, preventing cross-user data access
- **Zod everywhere** — All API inputs validated server-side with Zod before hitting the database

## Getting Started

### Prerequisites

- Node.js >= 20
- npm >= 10
- A [Supabase](https://supabase.com) account (free)
- A [Google Cloud](https://console.cloud.google.com) project with OAuth credentials
- A [Google AI Studio](https://aistudio.google.com) API key (Gemini)
- An [Anthropic](https://console.anthropic.com) API key

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/finsight.git
cd finsight

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env.local
# Fill in all values in .env.local (see Environment Variables section)

# 4. Push database schema to Supabase
npx prisma db push

# 5. Generate Prisma client
npx prisma generate

# 6. Seed demo data
npm run db:seed

# 7. Start development server
npm run dev
```

App runs at `http://localhost:3000`

### Environment Variables

```env
# App
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=<generate with: openssl rand -base64 32>
NEXT_PUBLIC_APP_URL=http://localhost:3000

# Database — Supabase PostgreSQL
DATABASE_URL=postgresql://postgres.[ref]:[password]@aws-0-[region].pooler.supabase.com:6543/postgres?pgbouncer=true
DIRECT_URL=postgresql://postgres.[ref]:[password]@aws-0-[region].pooler.supabase.com:5432/postgres

# Google OAuth — console.cloud.google.com
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=

# Google Gemini — aistudio.google.com → Get API Key
GOOGLE_AI_API_KEY=AIza...
```

## Deployment

### Vercel (Recommended)

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod
```

Set all environment variables in Vercel dashboard. The build command is `npm run build`.

### Database (Supabase)

1. Create a new Supabase project
2. Copy the connection strings from Project Settings → Database
3. Use the **pooler** URL for `DATABASE_URL` and the **direct** URL for `DIRECT_URL`
4. Run `npx prisma db push` to create tables
